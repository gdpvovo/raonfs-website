## What's Working

1. The chip↔tag colour system is real engineering. Hues derived in OKLCH; dot lightness deliberately staggered (.50/.58/.66) because 공공/호텔 collapsed to ΔE 5 under deuteranopia at uniform lightness, lifting worst case to ΔE 16. Pills hold 7.7–8.3:1; hues skip the 220–265 band so nothing competes with the action blue; colour never codes alone — which matters concretely because "업무시설" appears under three different categories.
2. The print stylesheet is domain-aware. 회사지명원 is routinely printed/PDF'd by 발주처; the stylesheet restores the 35 folded rows for print while still respecting the active filter, which is why the JS marks fold-hidden rows separately from filter-hidden ones.
3. Progressive-enhancement discipline: `.reveal` gated on a `.js` class so a dead script cannot blank the page; cert triggers are real `<a href>` with modifier-key detection; `inert` on header/main/footer while the modal is open.

## Priority Issues

### [P0] The page never asks for the business; the closing section is a map
The conversion path ends at `#contact`, whose h2 reads "오시는 길 / Location Map". Both the header CTA (문의하기) and the hero CTA (연락처 확인) deposit the visitor there, where they find an address list, a static Naver Map PNG, and two buttons — one of which navigates off-site. No 견적/입찰 form, no 회사소개서 PDF, no named contact, no business hours, no response-time promise, no closing statement.
Why it matters: the visitor's job is "decide whether to bid-list this company, then get the paperwork." The site's final answer is driving directions.
Fix: rename to 문의하기/Contact, demote the map inside it, and add (a) a 회사소개서(지명원) PDF download, (b) a 4-field 견적 문의 form or a prefilled mailto:, (c) one line of risk reduction — 담당 부서, 업무시간, 평균 회신 시간.
Suggested command: /impeccable onboard

### [P1] Credentials cannot be verified, and one expires in 17 days
(1) The six cards carry badge + name + English gloss only — no 인증번호, 발급기관, 유효기간. (2) The lightbox meant to close that gap crops the document. Measured at 1280x900: `.lightbox-body` clientHeight 704, image renders 848x1256, scrollHeight only 1010 — roughly 246px of the certificate is unreachable at any scroll position, because `max-height:100%` never resolves against an auto-height flex parent. The prev/next buttons are position:absolute inside that scroll container and drift with the content (measured 453 → 156 on a 300px scroll). This works correctly on mobile, where the panel is height:100% — a previous polish pass verified only mobile. (3) ISO 9001 states 유효기간 2026-08-28, 17 days out, while the hero asserts "인증 ISO 9001 · 45001" in unqualified present tense.
Fix: put 인증번호/발급기관/유효기간 as copyable text on each card; give the lightbox image a height:100% wrapper with object-fit:contain and move .lightbox-nav onto .lightbox-panel.
Suggested command: /impeccable harden

### [P1] The works table has no dates and contains work predating the company
Columns are 발주처/공사명/건물 유형 — no 연도, 기간, or 규모. The hero states 설립 2015, yet the table lists 현대자동차 본사 사옥 신축공사 (양재동) and 구서울역사 원형복원 사업, completed years earlier, with no disclosure line. Separately, filtering 군부대 returns 3 of 45 rows while 주한미군 occupies the title tag, the hero lead, one of three business fields, and its own org-chart division.
Fix: add a sortable 연도 column; if pre-2015 work is the principals' career record, say so in one line above the table — that converts a credibility hole into a credibility asset.
Suggested command: /impeccable clarify

### [P1] On mobile the colour system is off-screen and there is no way to call
At 375px `.table-wrap` is 325px against a table locked at min-width 660px, so the 건물 유형 column — every colour tag the seven chips exist to reveal — sits outside the viewport; tapping a chip changes nothing visible. `.header-cta` is display:none below 900px, so with the drawer closed there is no contact affordance on screen at any scroll position. The drawer sets no body.is-locked, has no backdrop, and closes only on link click or Escape — unreachable on a phone.
Fix: below 768px render each project as a stacked card; add a sticky bottom bar with 전화 문의; add a backdrop with click handler and scroll lock to the drawer.
Suggested command: /impeccable adapt

### [P2] The PPT running order buries the proof behind the boilerplate
At 1280px the document is 8,809px tall. 사업실적 starts at y=4,460 (51% depth), 면허·인증 at y=6,907 (78%). Ahead of them sit 미션 (reprints the hero headline verbatim plus four paragraphs of deck prose) and 조직도 (nine unnamed boxes whose connector lines terminate in whitespace — vertical ::before stubs with no horizontal rail).
Fix: reorder for the web — hero → 사업실적 (with a compressed client-name row under the hero) → 면허·인증 → 취급 시스템 → 회사소개 → 연혁 → 문의. Merge 미션 into 회사소개 as one paragraph.
