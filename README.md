# 라온에프에스 기업 사이트

주식회사 라온에프에스(Raon FS) 공식 홈페이지. 소방시설 전문공사 · 설계 · 주한미군 납품공사.

**운영 주소:** https://www.raongr.com

## 구조

빌드 과정이 없는 정적 사이트입니다. 프레임워크도, 패키지 설치도, 컴파일도 필요 없습니다.

```
index.html              단일 페이지 (전 섹션 포함)
css/style.css           전체 스타일 · 디자인 토큰
js/main.js              필터 · 라이트박스 · 드로어 · 스크롤 동작
assets/                 로고, 지도, 제품 사진, 인증서, 회사지명원 PDF
robots.txt · sitemap.xml
netlify.toml            배포 설정 (캐시 · 보안 헤더)
.htaccess               Apache 호스팅용 (Netlify에서는 미사용)
DESIGN.md               디자인 시스템 명세
.impeccable/design.json 디자인 토큰 사이드카
```

## 로컬에서 보기

```bash
python3 -m http.server 4173 --directory .
```

브라우저에서 `http://localhost:4173` 접속. 종료는 `Ctrl+C`.

`index.html`을 브라우저로 바로 열어도 대부분 동작하지만, PDF 다운로드처럼 경로를 타는 기능은 위 방식으로 확인하는 편이 정확합니다.

## 배포

`main` 브랜치에 push하면 Netlify가 자동으로 배포합니다.

## 수정할 때

- **색·간격·서체**는 `css/style.css` 최상단의 `:root` 토큰에서 관리합니다. 개별 규칙을 직접 고치기 전에 토큰을 먼저 확인하세요.
- **디자인 판단 기준**은 `DESIGN.md`에 정리돼 있습니다. 새 화면이나 요소를 추가할 때 참고하면 톤이 어긋나지 않습니다.
- **실적 데이터**는 `index.html`의 `#worksBody` 안에 있습니다. 각 행의 `data-cat` 값이 필터 분류와 색상을 결정합니다.

## 알려진 미완성 항목

- 실적 표에 **시공 연도 열이 없습니다.** 원본 회사지명원에 연도 정보가 없어 비워 두었습니다. 연도를 확보하면 정렬 가능한 열로 추가할 수 있습니다.
- 2015년 창립 이전 공사가 표에 포함돼 있습니다. 대표·임직원의 경력 실적이라면 표 상단에 그 사실을 한 줄로 밝히는 편이 좋습니다.
